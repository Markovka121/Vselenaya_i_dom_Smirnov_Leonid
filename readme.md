# Назначение
Назначается для изучения планет и самой солнечной системы в которую входят эти планеты

## Как запустить

* Запускается в браузере

## Как пользоваться

1. Листаешь вниз и получаешь информацию
2. Чтобы перейти на вторую страницу нажмите `Перейти к планетам солнечной системы` оно выделено синим
